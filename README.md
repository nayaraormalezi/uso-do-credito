# Uso do Crédito — CAIXA Consórcio

Protótipo desktop da jornada **Uso do Crédito · Imobiliário**, evolutiva da jornada APP do Figma com as oportunidades do board de CX Private.

## Rodar

```bash
cd web
npm install
npm run dev
```

App em `http://localhost:5173`.

## O que está no protótipo

- Shell desktop 3 colunas (stepper · conteúdo · central de acionamentos)
- Fluxo P0 de Aquisição completo até acompanhamento
- Badge Private, gerente, pendências acionáveis, reuso de documentos
- Tracking pós-envio com papéis (cliente / CAIXA / gerente)

Arquitetura detalhada: canvas no projeto Cursor (`arquitetura-jornada-desktop.canvas.tsx`).
